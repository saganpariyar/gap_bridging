# Gap Bridging (Chasm Tether)

A 2D co-op physics puzzle-action Flutter game where the **Light** glider crosses wide canyon chasms and locks into place, allowing the **Heavy** companion to swing and reel safely across.

## Features
- **6 Progressive Chasm Levels** with wind thermals, hanging stalactite arches, relay spires, and collectible Energy Cores.
- **Customization Studio (4 Options Per Selection):**
  - 4 Light Player Profiles (`Aero-Wisp`, `Volt-Sprite`, `Solar-Falcon`, `Nebula-Lynx`)
  - 4 Heavy Player Profiles (`Titan-Core`, `Bastion-MK4`, `Magma-Atlas`, `Jade-Bulwark`)
  - 4 Canyon Backgrounds (`Twilight Canyon`, `Emerald Spires`, `Sunset Mesa`, `Crystal Abyss`)
  - 4 Tether Cable Styles & 4 Pilot Emblem Badges
- **Solo Swap & 2P Local Split Controls** + Keyboard (`WASD` / `Arrow Keys` / `Space` / `Tab`).

## Run
Double-click `run_app.bat` or run:
```bash
flutter run -d chrome
```
